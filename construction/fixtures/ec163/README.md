# EC163 synthetic file metadata fixtures

These invented GitHub/GitLab examples are NOT real API results, not authorization,
and not final provider acceptance. They intentionally contain `patch` / `diff`
markers proving that the paths consumer discards sensitive server response fields.

`github.synthetic.files.json`: modified, renamed, added; numeric line counts.
`gitlab.synthetic.diffs.json`: renamed and collapsed; no line counts.
The fixtures must be used only with an injected synthetic transport.

# 1.0 基准说明

版本统一为 1.0.0。当前入口、README 和使用说明不再使用施工轮次作为产品版本。逐轮报告、未引用阶段快照、旧总状态和历史文档已移出工作目录，测试只保留本轮最终验证证据。

1.0 以当前修复后的字节重建源码锁和响应契约；它是新的本地基准，不是对原始包历史校验值的改写。整理前源文件和原始日志另有压缩备份。

兼容性标识包括 Python 包导入名、schema ID、哈希域、路由类别和错误码。它们关系到已有请求及证据的验证，因此保留内部标识。原来的 construction/ 路径也保留，以免引入无关的模块迁移。

BASELINE_SHA256.json 是未签名的当前文件一致性清单，不提供外部身份或生产验收背书。验证结果与限制见 VALIDATION.md 和 KNOWN_ISSUES.md。
